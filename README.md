# 📈 Stock Market Data Analyzer

A Python-based financial data analysis project that retrieves, processes, analyzes, and visualizes stock market data to understand stock performance, market trends, and investment-related risk indicators.

The application supports both live stock market data through Yahoo Finance and an offline sample dataset for testing and demonstration.

## 🚀 Project Overview

The Stock Market Data Analyzer is designed to transform raw stock market data into meaningful analytical insights.

It calculates technical indicators, evaluates historical stock performance, measures market risk, and generates visual reports to make financial data easier to understand.

This project demonstrates practical applications of Python programming, data analytics, financial analysis, and data visualization.

## ✨ Key Features

- **Live Stock Data:** Retrieve historical stock data using Yahoo Finance.
- **Offline Data Analysis:** Analyze a synthetic sample dataset without an internet connection.
- **Data Preprocessing:** Clean, validate, and organize stock market data.
- **Technical Indicators:** Calculate 20-day and 50-day Simple Moving Averages (SMA).
- **Daily Returns:** Calculate daily percentage price changes.
- **Trend Analysis:** Identify upward, downward, and sideways price trends.
- **Risk Analysis:** Evaluate annualized volatility and maximum drawdown.
- **Data Visualization:** Generate stock price charts, moving average charts, and daily return distributions.
- **Automated Reports:** Generate text
